# 通知筛选

当前规则按 示例中的 2026 级研一学生的使用场景整理。

1. 直接 @ 本人优先保留。
2. 明确其他年级、研二研三、博士、毕业生专属任务跳过；没有明确包含本人的开题、中期、答辩通知跳过。
3. 明确自愿报名、其他专业指定人员、已报名名单的活动默认不自动提醒。
4. 包含本人年级或全体学生的通知保留；其他情况交给 AI 做相关性判断。
5. 模型失败时保留可能相关通知，并用规则提炼，降低漏掉必要事务的风险。

`@全体成员` 只是消息触发条件，不等于内容适用于所有人。

`.env` 的 `STUDENT_COHORT` 和 `STUDENT_PROFILE` 可配置入学年与身份。但研一/研二、开题等快速规则目前仍按研一语义编写，升年级后应同步修改 `qq_relevance.py` 并跑测试，不能仅改简介就认为规则自动升级。

已知限制：规则依靠文本而不是完整历史上下文；特殊身份（班干部、受灾、已报名等）无法自动核实；多对象混合通知、转发、否定句仍可能误判。图片和文件目前只提取占位文字，不做 OCR 或读取附件。跨群相同内容仅按消息 ID 去重，仍可能产生重复提醒。AI 不是最终事实来源，应以原通知为准。
